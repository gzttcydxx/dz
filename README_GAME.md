# 对抗影渊 - 游戏功能说明

## 游戏系统已实现

### 核心功能
1. **房间系统**：创建和加入游戏房间
2. **角色选择**：4种角色，每种3个颜色变体
3. **实时对战**：基于WebSocket的实时多人游戏

### 游戏操作
- **WASD**：上下左右移动
- **鼠标移动**：瞄准
- **鼠标左键**：射击
- **R键**：换弹

### 角色武器系统

#### 勇者（已实现）
- 武器：左轮枪
- 射击间隔：0.7秒
- 子弹速度：30
- 弹道大小：10
- 伤害：200点
- 弹夹容量：6发
- 换弹时间：2.0秒

#### 骑士（已配置）
- 武器：霰弹枪
- 射击间隔：1.0秒
- 子弹速度：25
- 弹道大小：8
- 伤害：150点（每颗）
- 每次发射：5颗子弹
- 弹夹容量：8发
- 换弹时间：2.5秒

#### 法师（已配置）
- 武器：魔法杖
- 射击间隔：0.3秒
- 子弹速度：35
- 弹道大小：12
- 伤害：100点
- 弹夹容量：20发
- 换弹时间：1.5秒

#### 刺客（已配置）
- 武器：弩箭
- 射击间隔：0.5秒
- 子弹速度：40
- 弹道大小：6
- 伤害：250点
- 弹夹容量：10发
- 换弹时间：1.8秒

### 游戏界面

#### HUD显示
- **血量条**：左下角显示当前血量/最大血量
- **弹药显示**：右下角显示当前弹药/弹夹容量
- **玩家列表**：右上角显示所有玩家及其血量
- **准星**：红色十字准星跟随鼠标
- **换弹提示**：屏幕中央显示换弹状态

#### 视觉效果
- 玩家以彩色圆圈表示，带有方向指示线
- 玩家头顶显示名字和血量条
- 子弹带有黄色轨迹效果
- 地图背景图片（需要添加到 `static/maps/` 文件夹）

### 网络同步
- 玩家位置实时同步
- 射击和子弹轨迹同步
- 伤害判定和血量同步
- 玩家加入/离开通知

## 如何添加地图图片

1. 准备PNG或JPG格式的地图背景图片
2. 将图片命名为地图名称，例如：`寒清境.png`
3. 将图片放入 `static/maps/` 文件夹
4. 游戏会自动加载对应的背景图片

## 调试说明

游戏包含详细的调试输出：
- 后端（Python控制台）：显示房间创建、玩家加入、游戏状态等
- 前端（浏览器控制台）：显示Socket连接、游戏事件、玩家操作等

按 F12 打开浏览器开发者工具查看前端调试信息。
