调试指南 - 玩家名和房主权限问题
====================================

## 问题描述
1. 房主无法看到"更改房间设置"按钮
2. 玩家列表中显示的名字不是创建房间时输入的名字

## 调试步骤

### 第一步：打开浏览器开发者工具
1. 访问 http://localhost:5000
2. 按 F12 打开开发者工具
3. 切换到"控制台"(Console)标签

### 第二步：创建房间并观察日志
1. 点击"开始游戏"
2. 点击"创建房间"
3. 输入你的名字（例如："张三"）
4. 选择其他设置
5. 点击"确认创建"

### 第三步：检查浏览器控制台输出
应该看到以下日志：
```
=== Socket连接成功 ===
房间密钥: XXXXXX
玩家名字(PLAYER_NAME): 张三
PLAYER_NAME类型: string
PLAYER_NAME是否为空: false

===== 房间信息更新 =====
当前玩家ID: xxxxx
房主ID: xxxxx
是否房主: true
当前玩家信息: {id: "xxx", name: "张三", ready: false, is_host: true, avatar: {...}}
玩家列表: [{...}]
======================

roomSettingsBtn元素: [button#roomSettingsBtn]
✅ 房主身份确认，显示房间设置按钮
```

### 第四步：检查服务器控制台输出
在运行Python的终端窗口中应该看到：
```
=== join_room_session 调试信息 ===
房间密钥: XXXXXX
玩家名字: 张三
Session ID: xxxxxx
房主名字: 张三
当前房间玩家: []
是否房主: True
添加新玩家: 张三, 角色: {'character': 'xxx', 'color': x}
...
```

## 常见问题和解决方法

### 问题1：PLAYER_NAME显示为空字符串或"玩家"
**可能原因**：Session没有正确保存
**解决方法**：检查lobby.html中PLAYER_NAME是否正确传递

### 问题2：是否房主显示为false
**可能原因**：
- 玩家名字不匹配
- Session ID更新后没有正确识别
**解决方法**：对比服务器日志中的"玩家名字"和"房主名字"

### 问题3：roomSettingsBtn为null
**可能原因**：HTML元素ID不匹配
**解决方法**：检查lobby.html中按钮ID是否为"roomSettingsBtn"
